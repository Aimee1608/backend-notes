# 模型市场怎么看：参数怎么读，去哪查

这篇不告诉你"哪个模型最好"——模型几个月一更新，任何具体结论写下来就开始过期。这篇教的是**怎么读懂模型的参数表，以及去哪查最新信息**。授人以渔。

---

## 当前的市场格局（框架性认知）

主流玩家分三类：

**闭源旗舰**：OpenAI（GPT 系）、Anthropic（Claude 系）、Google（Gemini 系）。只能通过 API 或云平台调用，能力最强的第一梯队。

**开源权重阵营**：DeepSeek、Meta（Llama 系）、阿里（Qwen 系）、Mistral 等。模型权重可下载，可以自己部署。能力与闭源旗舰的差距在持续缩小，性价比常常是优势项。

**云平台聚合**：AWS Bedrock、Azure、GCP 以及各类模型网关，聚合多家模型统一接入。企业采购常走这条路（合规、计费统一）。

格局的关键特征：**基础能力在收敛，侧重点在分化**。长上下文、多模态、工具调用已是标配；各家真正的差异在专项——有的强在代码，有的强在多模态，有的强在价格。所以选型问题永远是"哪个适合我的场景"，不是"哪个最强"。

## 参数表怎么读

打开任何一家的模型介绍页，重点看这几项：

### 上下文窗口（Context Window）

模型一次请求能处理的最大 token 量（输入+输出合计）。当前旗舰普遍在 1M（百万）量级。

读这个数字要注意：**窗口大小 ≠ 有效利用能力**。能塞进 1M token 和能把 1M token 里的信息都用好，是两回事（长上下文的"中间遗忘"问题，第 11 篇细讲）。有些厂商会单独公布长上下文的检索准确率测试，那个更值得看。

### 定价（Pricing）

按 token 计费，重点看四个数字：

- **输入价**（per million input tokens）
- **输出价**：通常是输入价的 3-5 倍
- **缓存写入/读取价**：Prompt Cache 命中时读取价可以低到输入价的十分之一，对高频调用场景影响巨大
- **思考 token**：按输出价计费——开思考模式的真实成本要算上它

对比价格时要用**自己场景的输入输出比例**估算，不能只看单价。输入长输出短的场景（文档问答）和输入短输出长的场景（内容生成），对同一张价目表的敏感点完全不同。

### 能力标签

- **Thinking / Reasoning**：支持思考模式，通常带预算控制
- **Vision**：能看图；再进一步的还有音频、视频输入
- **Tool Use / Function Calling**：工具调用可靠性（都支持，但稳定度有差异）
- **Structured Output**：原生 JSON Schema 输出约束
- **Computer Use**：能操作图形界面（较新的能力，成熟度看评测）

### 速度指标

- **首 token 延迟（TTFT）**：影响对话体感
- **生成速度（tokens/s）**：影响长输出的总时长

同一家通常有旗舰版和快速版（如 Pro/Flash、大杯/小杯）：旗舰强而慢贵，快速版弱而快便宜。**生产系统常见做法是两者搭配**——简单请求走快速版，复杂请求走旗舰。

## 去哪查最新信息

一手信息（参数、价格以官方为准）：

- 各厂商的 **官方文档和定价页**——模型参数、价格、能力列表的唯一权威来源
- 各厂商的 **官方博客 / 发布公告**——新模型的能力说明

第三方横向对比（快速建立全局感）：

- **Artificial Analysis**（artificialanalysis.ai）——各模型的能力、价格、速度横向对比，数据更新快
- **LMArena**（竞技场盲测排名）——真实用户盲测投票的 Elo 排名，反映"体感"而非跑分
- **各类 Benchmark 榜单**——SWE-bench（代码）、GPQA（推理）等专项排名，怎么读榜第 07 篇专门讲

使用姿势：**第三方站建立初步印象 → 官方文档核实参数价格 → 自己的场景实测做最终决定**。任何榜单都替代不了拿自己的真实任务跑一遍。

---

## 选型的决策顺序

按这个顺序过滤，通常很快能缩小到两三个候选：

1. **硬约束先筛**：数据能不能出境/给第三方？必须私有化部署？→ 直接筛掉一大半
2. **能力需求筛**：要不要看图？要不要 Computer Use？上下文要多长？
3. **成本框架筛**：按预估调用量算月账单，超预算的出局
4. **剩下的实测**：拿 20-50 个真实任务样本，候选模型各跑一遍，人工看结果

最后一步没有捷径。榜单分数是别人的任务，你的场景只有你自己测了才知道。
