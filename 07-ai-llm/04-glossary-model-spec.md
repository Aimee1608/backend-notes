# 模型规格词扫盲：发布公告里的参数都什么意思

每次新模型发布，公告里都是这样的句子："670B 参数 MoE 架构，激活参数 37B，提供 FP8 量化版本，开源权重。"

每个词都认识，连起来不知道在说什么。这篇把模型规格相关的黑话一次扫清。

---

## 7B / 70B / 405B：参数量

**参数（Parameters）**是模型内部可调节的数值，训练的过程就是在调这些数。B 是 Billion（十亿）——7B 就是 70 亿参数，405B 就是 4050 亿。

直觉上参数越多能力越强，但这个关系近年在松动：

- 训练数据质量和训练方法的影响越来越大，小模型通过更好的训练追赶大模型的例子屡见不鲜
- 同参数量的模型，不同代际能力差距巨大——今天的 7B 能打赢三年前的 70B

参数量真正直接决定的是**部署成本**：参数越多，需要的显存越大、推理越慢。这就是为什么参数量是开源模型的核心指标（你要自己扛部署成本），而闭源 API 模型很多根本不公布参数量（成本是厂商的事，你只管按 token 付费）。

---

## Dense vs MoE：稠密与混合专家

**Dense（稠密模型）**：每次推理，所有参数都参与计算。传统结构，70B 的 Dense 模型每生成一个 token 都要动用全部 70B 参数。

**MoE（Mixture of Experts，混合专家）**：把模型内部分成多组"专家"，每次推理只激活其中几组。公告里"670B 参数、激活 37B"的意思就是：总参数 670B，但处理每个 token 时只有 37B 在干活。

MoE 的好处：**能力接近大参数量，计算成本接近小参数量**——户口本上是巨无霸，饭量只是中等身材。这几年旗舰模型广泛转向 MoE 架构，就是为了在能力和推理成本之间找更好的平衡。

看规格时的实用结论：MoE 模型要同时看总参数（决定显存占用——所有专家都要装进显存）和激活参数（决定计算速度）。

---

## 蒸馏（Distillation）：大模型教小模型

用一个强大的"教师模型"生成大量高质量的问答数据，拿去训练一个小的"学生模型"，让小模型学到大模型的行为方式。

这就是为什么很多小模型的发布词是"性能接近 XX 旗舰"——它就是拿那个量级的模型蒸馏出来的。蒸馏是目前小模型质量突飞猛进的主要推手之一。

对使用者的意义：**同系列的小杯模型往往是大杯蒸馏来的**，行为风格相似、能力打折、价格便宜很多。这是"简单任务用小杯"这个降本策略能成立的基础——它们不只是便宜，还"像"。

---

## 量化（Quantization）：压缩精度换资源

模型参数本来用高精度数字存储（如 16 位浮点，FP16）。量化就是把精度压低——FP8、INT8、INT4——每个参数占的空间减半再减半。

效果立竿见影：显存占用大幅下降，推理速度提升，一张消费级显卡跑不动的模型，量化后可能就跑得动了。

代价是精度损失带来的能力下降——通常量化到 8 位损失很小，压到 4 位及以下损失开始明显，具体看模型和任务。

这个词主要出现在**自己部署开源模型**的场景：下载模型时会看到同一个模型的 FP16 / FP8 / INT4 多个版本，按自己的硬件条件和质量要求选。调闭源 API 的话不用关心这事。

---

## 开源权重 vs 闭源

**开源权重（Open Weights）**：模型的参数文件公开可下载，你可以自己部署、微调。注意"开源权重"不等于传统意义的开源——训练数据和训练代码通常不公开，且商用许可各家条款不同，用之前要看 license。

**闭源**：只能通过官方 API 调用，模型文件拿不到。

选择的核心考量不是意识形态，是工程现实：

- 数据绝对不能出内网 → 只能开源权重自己部署
- 想要最强能力、不想管运维 → 闭源 API 省心
- 量大到 API 账单爆炸 → 自部署开源模型可能更便宜（但要算上 GPU 和运维的真实成本）

---

## Base 模型 vs Instruct 模型

下载开源模型时会看到同一个模型有两个版本，比如 `Xxx-70B-Base` 和 `Xxx-70B-Instruct`。

**Base（基座模型）**：只做了预训练的"原始"模型。它只会一件事——续写文本。你问它"中国的首都是哪里？"，它可能回你"这是一道常见的地理题。类似的题目还有……"——因为在训练数据里，一个问题后面跟着的经常是更多问题，而不是答案。

**Instruct（指令模型）**：在 Base 基础上做了指令微调和对齐训练，学会了"用户在提问，我该回答"这个对话模式。**日常使用和应用开发，用的都是 Instruct 版本。**

Base 版本给谁用？给要做深度定制训练的团队——从"未调教"的基座开始，往自己的方向训练。普通应用开发者可以无视 Base 版。

## 读一段真实风格的发布词试试

"本次发布 236B 参数 MoE 模型，激活参数 21B，开源权重，提供 Instruct 版本及 FP8 量化版，另有 16B 蒸馏小模型同步发布。"

翻译成人话：总参数 2360 亿但每次只用 210 亿在算（能力大杯、算力中杯）；权重可下载自部署；已调教成能对话的版本；有压缩版对显存友好；还配了个拿它蒸馏出来的小模型给资源紧张的场景用。

下次再看发布公告，应该能直接读懂了。
