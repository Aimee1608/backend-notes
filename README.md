# backend-notes

> **研发都要懂的事** —— 一个研发,把工作里绕不开的技术、架构、平台、成本……一块块搞懂的真实笔记。
> 每个主题 = 一个可运行的 demo + 一篇图文笔记,全部从**公开标准**(RFC / 官方文档 / 开源项目)重新学一遍。

公众号:**Aimee写代码**(合集《研发都要懂的事》) · 博客:[mangoya.cn](https://mangoya.cn)

## 为什么有这个仓库

我平时用 Node.js 做开发,但工作里绕不开的很多事(鉴权、数据建模、定时任务、监控、成本……)只停留在"大概会用"。
这个仓库记录我把它们**一个个搞懂**的过程:不堆砌概念,带着真实问题学,自己写 demo、自己踩坑,再用大白话讲清楚。
